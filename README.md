# 🛒 Frontend E-Commerce Web App

A modern **frontend-only e-commerce web application** built using **React and Tailwind CSS**.
This project simulates a real online store with product browsing, search, filtering, and a shopping cart system using **mock data**.

The goal of this project is to practice **React component architecture, state management, and responsive UI design** while building a clean and scalable e-commerce interface.

---

## 🚀 Features

* 🏠 **Home Page**

  * Hero section with promotional banner
  * Featured products
  * Product categories

* 🛍 **Product Listing**

  * Responsive product grid
  * Search products
  * Category filtering
  * Sorting by price or rating

* 📦 **Product Details Page**

  * Product images
  * Detailed description
  * Rating and price
  * Add to cart functionality

* 🛒 **Shopping Cart**

  * Add / remove products
  * Update product quantity
  * Automatic total price calculation
  * Cart persistence using **localStorage**

* 🎨 **Modern UI/UX**

  * Built with Tailwind CSS
  * Responsive design (mobile + desktop)
  * Smooth hover animations
  * Clean product card layout

---

## 🧑‍💻 Tech Stack
